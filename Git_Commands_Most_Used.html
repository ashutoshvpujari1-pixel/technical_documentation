Git Commands Reference Guide

A professional quick-reference guide for common Git workflows - Created by Ashutosh Pujari

Quick Start: Run the commands below from your working folder to initialize a Git repository, configure your identity, commit files, connect a remote repository, and manage branches and changes.

1 Repository Setup 

git init
git config --global user.email "username@gmail.com"
git config --global user.name "User Name"

2 Add, Status & Commit 

git add .
git status
git commit -m "Adding files"

3 Remote Repository & Push 

git remote add origin https://hithub.com/username/project_name.git
git push origin master
Alternative 
git push --set--upstream origin master

4 Pull Changes 

git pull https://hithub.com/username/project_name.git

5 Branch Management

Create a New Branch

git branch <new-branch-name>
git branch branch_developer1

Delete a Branch

git branch -D <new-branch-name>

Go to a New Branch

git checkout <new-branch-name>

Show List of Branches

git branch

6 View Recent Activities 

git log
git log --graph --pretty=oneline

7 Stash Changes 

git stash
git stash -u
git stash pop

8 Revert a Commit 

git revert <commit_id>
Note: Use git log to obtain the required commit ID.

9 Compare Commits 

git diff <commit_id1> <commit_id2>
Note: Commit IDs can be obtained by running git log.

10 Merge Branches 

git merge
git merge <source-branch>
Workflow: First checkout to the master branch. Then run git merge <feature-branch>. 
git checkout master
git merge <feature-branch>

11 Rebase Branches 

git rebase
git rebase <source-branch>
Note: Rebasing can be used to bring the latest changes from the master branch into a feature branch. 
git checkout feature_branch
git rebase master

12 Common Git Workflow

Initialize

Create a Git repository using git init.

Stage

Add files with git add ..

Commit

Save changes using git commit.

Push

Upload commits to the remote repository.

Branch

Create isolated development branches.

Merge / Rebase

Integrate changes between branches.
