Invoking a REST API from Java

This example creates an Employee object, sends it as JSON using HTTP POST, and maps the API response back to an Employee object.

Java Client Code

RestClient restClient = RestClient.create();

Employee employee = new Employee();
employee.setId(101);
employee.setName("Anand");
employee.setDepartment("IT");

Employee response = restClient.post()
        .uri("http://localhost:8080/api/employees")
        .contentType(MediaType.APPLICATION_JSON)
        .body(employee)
        .retrieve()
        .body(Employee.class);
