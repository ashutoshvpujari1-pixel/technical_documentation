Request Flow

A simple example of how a request can travel through the architecture.

1

Client Request

The client sends an HTTP request to the API Gateway rather than directly depending on every microservice.

2

Gateway Routing

The Gateway examines the incoming URL path and forwards the request to the appropriate downstream service.

3

Service Processing

The selected microservice processes the request. When required, rest-second can invoke rest-first.

4

Response

The response travels back through the request chain to the client.
