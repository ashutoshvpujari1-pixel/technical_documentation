How to invoke Employee CRUD REST APIs using RestMan

localhost:8080
GET Retrieve Employee Details
In RestMan, select GET, enter the URL, then click Send.
All Employees
http://localhost:8080/api/employees
Single Employee
http://localhost:8080/api/employees/101
Response: JSON containing employee details
POST Create Employee
Select POST in RestMan and add the JSON body below.
URL
http://localhost:8080/api/employees
Header
Content-Type: application/json
{ "id": 103, "name": "Anil", "department": "IT", "salary": 75000 }
PUT Update Employee
Select PUT in RestMan and send the updated employee JSON.
URL
http://localhost:8080/api/employees/103
Header
Content-Type: application/json
{ "id": 103, "name": "Anil Kumar", "department": "IT", "salary": 77000 }
DELETE Delete Employee
Select DELETE in RestMan, enter the employee URL, then click Send.
URL
http://localhost:8080/api/employees/101
Result: Employee 101 will be deleted
